# Neurons · src/contracts

refreshed 2026-10-14T19:15:56Z · 8eebea37f816

- `src/contracts/tank/**` is vendored, generated code from `tactical-agent-neural-knowledge/contracts` — never hand-edit it; the only way to change it is `pnpm sync-contracts <contracts-sha>`.
- `src/contracts/VERSION` is the single source of truth for "which proto revision": currently `e52a377a71d9116560dab77ea76365959835a082`. After any sync, `pnpm build` and commit the rebuilt `dist/` in the same change.
- This sync added five new vendored packages as flat shims — `board`, `books`, `canvas`, `remediation`, `security` — each a one-line re-export (`export * from "./tank/<pkg>/v1/<pkg>_pb.js";`), generated with the `// Generated by scripts/sync-contracts.sh — do not edit.` header.
- `src/contracts/index.ts` is the one hand-maintained file here: a namespaced barrel (`export * as <pkg> from ...`) that exists specifically so same-named messages in different packages don't collide (`SetStatusRequest` in both `presence` and `agent`).
- The barrel is **not** 1:1 with the shims and needs a manual line per new package: it currently covers 14 namespaces (`agent, auth, blocks, channel, events, files, huddle, message, notification, presence, realtime, richtext, search, workspace`) while `src/contracts/*.ts` has 28 shim files — `admin, agentctl, billing, board, books, canvas, catalog, command, monitor, platform, remediation, security, topo` are reachable only via `./contracts/<pkg>` (the wildcard subpath), not via the `index.ts` barrel import.
- `@bufbuild/protobuf` v2 message shapes from these vendored types are used directly as store message types in `src/client/store.ts` — there are no parallel hand-written DTOs to keep in sync.
- `EventPayload`/`KnownEventPayload` (built from these types, consumed in `src/client/realtime.ts` and `store.ts`) is a closed union keyed on the literal `$typeName` discriminant, with a `{ $typeName: "unknown", typeUrl, value }` fallback — an open `{ $typeName: string }` member would defeat `switch` narrowing.
- `biome.json` excludes `src/contracts/tank` from lint/format but **not** the flat shims or `index.ts` — a hand-edit to a shim still has to pass Biome.
- A vendored package having a shim (and sometimes a barrel entry) does not mean its event types are wired into the store: the five packages added this sync (`board`, `books`, `canvas`, `remediation`, `security`) ship new `CanvasBlockChanged`/`CanvasChanged`/`BoardObjectsChanged`/`BoardChanged` events that decode via `KnownEventPayload` but have no `case` in `envelopeToActions` yet — see `.neural/neurons/src-client.md`.
