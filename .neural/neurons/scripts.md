# Neurons · scripts

refreshed 2026-10-04 · 5378a111dd9c

- `scripts/sync-contracts.sh` is the only script in the repo and the only sanctioned way to change `src/contracts/tank/`; run it as `pnpm sync-contracts <contracts-sha>`.
- It shallow-clones `tactical-agent-neural-knowledge/contracts` at the given sha and aborts unless `gen/ts/src/tank` exists there, so a sha from before the generated output moved fails fast instead of emptying the vendored tree.
- It replaces `src/contracts/tank` wholesale (delete then copy) — local edits inside that directory are destroyed, which is exactly why hand-editing it is a listed prohibition in `CLAUDE.md`.
- It writes the sha to `src/contracts/VERSION`; that file is the record of which contracts revision the SDK is built against (currently `25ae9cf68709430b10142bd1987e5586f2255dba`).
- It regenerates the flat per-package shims (`src/contracts/<pkg>.ts`), each stamped `// Generated by scripts/sync-contracts.sh — do not edit.` — a shim edited by hand is silently reverted on the next sync.
- The namespaced barrel `src/contracts/index.ts` is **not** generated: a new proto package needs a hand-written `export * as <pkg>` line there, and a matching `./contracts/<pkg>` entry is served by the `./contracts/*` wildcard in `package.json`.
- A sync is not finished until `pnpm build` is run and the resulting `dist/` is committed; CI fails on the stale `dist/` otherwise.
- The script touches no cloud account and needs no token — the contracts repo is cloned over public git, consistent with this repo's "no cloud identity" rule.
